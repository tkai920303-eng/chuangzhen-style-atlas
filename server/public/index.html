我的作品

这个仓库只提供参考库（风格 / 动效 / 光影）。你自己的作品库是另一回事—— 用仓库自带的扫描器索引你自己的目录，两边互不干扰：

npm run scan -- "D:/你的作品目录"   # 扫描并索引你自己的作品
npm start                            # 然后打开 http://127.0.0.1:5178/myworks

扫描结果写在仓库根目录的 我的作品/ 里，该目录已在 .gitignore 中， 你的作品不会被提交进这个公开仓库。

这是什么

  • 风格库：画面 / 配色 / 动法 / 光影四位一体的风格条目，每条给出可直接投喂给绘图或动效模型的提示词。
  • 动效库：运动语言条目，附时序、缓动、幅度三段参数，并提供去风格化的「白模版」，方便与任意风格混搭。
  • 光影库：光位、光质、光比、色温，配自产的布光示意图。
  • 每个条目都能一键复制提示词；动效条目在详情里可以直接播放循环预览动图。

本地运行

npm install     # 运行时零依赖，仅预览渲染工具需要 playwright-core
npm start       # 启动后打开 http://127.0.0.1:5178/atlas
npm run verify  # 校验三库结构、参考图引用与图鉴产物

接口

GET /api/atlas                 三个库的概要与分类
GET /api/atlas/styles            风格库全量（?q= 搜索，?cat= 分类）
GET /api/atlas/motions           动效库全量
GET /api/atlas/lighting          光影库全量
GET /atlas-img/<目录>/<文件>   参考图
