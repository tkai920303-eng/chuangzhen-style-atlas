## 怎么保持同步

本地素材库每增加内容，重跑一次同步即可：

```bash
node 04_工具\同步开源包.mjs
```

它会依次完成：重新导出 → 结构与引用验收 → 冒烟测试 → 泄露扫描 → 与上一版逐文件比对 →
输出变更清单（可直接写进 release notes）。
