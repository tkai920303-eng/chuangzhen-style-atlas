# 改动说明：README 配图与仓库封面图（2026-11-24）

## 这一轮做了什么

给公开仓库的 README 补上真正的画面，并额外产出一张可直接用作 GitHub 社交预览的封面图。

之前 README 是「纯文字 + 表格」结构：条目数、授权分布、接口列表都写得很清楚，但**看不到这个库长什么样**。
对一个视觉参考库来说，这是自述页最缺的东西——读者得先 clone 再跑起来，才知道 1162 张参考图长什么样。

这一轮的做法是：**用发布包自己的图鉴页面实拍**，不做插画、不做拼贴。拍出来的就是仓库里那套东西。

## 怎么拍的

新增两个本地工具（**不随包分发**，它们依赖本机环境）：

- `04_工具\生成README配图.mjs` —— 用 playwright-core 驱动本机 Chrome 打开图鉴页面，逐个页签切换、
  滚到底触发懒加载、等图片解码完再截图；条目抽屉那张是点开第一条后拍的。
  依赖 `04_工具\预览渲染\node_modules\playwright-core`（与预览渲染工具同一套，用 `createRequire` 从那个目录解析，
  避免把 `node_modules` 复制到 `04_工具` 根）。
- `04_工具\压缩README配图.py` —— 用 PIL 把 3200×2000 的 PNG 压成 1400 宽的 JPEG（质量 82），
  合计 8156 KB → 875 KB。
- `04_工具\生成仓库封面.py` —— 生成 1280×640 封面图。

### 一个关键约束：拍的对象必须是**发布包**

图鉴页面里有本地条目，出处字段会显示工程路径。开发态的图鉴里那些字段是**真实本机路径**，
拍出来就是发布事故。所以：

- 截图前先跑 `同步开源包.mjs` 重新导出，让发布包里的 `atlas.html` 是脱敏后的版本；
- 再起**发布包**的服务（`06_开源包\素材图鉴\server\server.mjs`）来拍，而不是开发态的工作台。

拍出来的抽屉图里，出处显示的是 `<私有工程>/15种风格学习与使用契机.md`——脱敏标记正确。

## 导出链改动

- `04_工具\paths.mjs`：新增 `IMG_SCREENSHOT = '界面截图'` 常量（与其他四个参考图目录同一套写法）。
- `04_工具\导出开源包.mjs`：`IMG_DIRS` 增加 `IMG_SCREENSHOT`，配图随包分发。

`tools/paths.mjs` 随包分发，它只多了一个目录名常量，不含任何本机路径与作品名，
仍然满足「随包脚本不得写死本地目录名 / 必须布局自适应」这条约束。

## 复核依据说明

配图是**渲染产物**，不是手工拼的，所以它的「正确性」由两件事保证：

1. 像素来自发布包自己的 `atlas.html`——与仓库公开内容同源，不存在「图与文不符」；
2. 截图前发布包已过脱敏与授权剔除，所以图里不会出现本机路径，也不会出现被剔除的受限主图。
