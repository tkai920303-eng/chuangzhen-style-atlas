# atlas 主参考图逐条署名表

本仓库 `assets/风格参考图/` 下的 atlas 主参考图，**每一张的权利状态都不同**。

atlas 的 API 只在 `effect.credit` 自由文本里交代主图的权利状态，`effect.image` 字段只有路径、没有 license。
atlas 自己的 SKILL.md 写明：

> Keep image author, source, and license with reused images;
> **public access does not imply unrestricted image licensing.**

所以下面这张表是**逐条判读**的结果。机器可读版本见 `data/atlas-image-credits.json`。
