# 改动说明 · 补剔高风险片格 + 纠正授权误判

日期：2026-11-23
范围：atlas 主参考图的授权判读规则（`04_工具/授权分类.mjs`）与随之而来的三库重建、发布包重导出
状态：**本地已完成，未提交、未发布**

## 背景

上一轮剔除 38 张版权保留主图时，判读规则只认 `©` / `copyright protected` / `all rights reserved` 这几个字面信号。
随后复核 108 张「授权不明」主图时发现，规则有两个盲点：

1. **认不出「片格」**。credit 写「RKO / Warner Bros.; via British Film Institute; Film still;
   **no open license stated**」的条目，没有 `©`、也没有 `copyright protected`，于是绕过了「版权保留」判定，
   和真正该剔的一批混在同一个低风险桶里。
2. **覆盖不到非 CC 表述的自由许可**。`GNU Free Documentation License` 与美国国会图书馆的
   `No known restrictions` 都不在规则的关键词表里，被判成「无明示授权」——实际上它们是**明确的**可再分发许可。

## 改动

### 1. 判读规则补信号（`04_工具/授权分类.mjs`）

判为**版权保留**新增三类信号：

| 信号 | 命中数量 |
|---|---:|
| credit 点名商业影视公司 / 工作室 / 版权权利人（Warner、Universal、Paramount、RKO、Fleischer、Image West、Pioneer Pictures、Ufa、MGM、Lucasfilm、Disney、Maya Deren、Man Ray、McQueen、NFB、BFI、Film Foundation、CineStill、ASC 等） | 16 |
| credit 自己写明 `no open license stated` | 10（含在上一行内） |
| credit 明确写版权保留 / 带 © 署名 | 原有 38 |

判为**可再分发**新增两类：

- `GNU Free Documentation License` → 新增判读类别 **GFDL**（可再分发，但需附 GFDL 全文并以相同许可分发）
- `no known restrictions`（美国国会图书馆声明）→ 归入**公有领域**

规则顺序上，明确的自由许可信号排在「点名权利人」之前——credit 若同时声明了 public domain / CC，以声明为准。

### 2. 补剔 16 张高风险片格

以下 16 张按版权保留处理，与已剔除的 38 张同类，随包不再分发：

`anamorphic-widescreen` `deep-focus-photography` `dolly-zoom` `halation` `pepper-s-ghost`
`rear-projection` `reverse-motion` `rotoscoping` `scanimate-analog-animation` `schufftan-process`
`slit-scan-photography` `slow-motion` `solarization` `stereoscopic-3d-cinema` `three-strip-technicolor` `traveling-mat`

剔除**只删图片文件并把条目的参考图引用置空**；条目文本、提示词、来源链接与逐条署名一条不少。

### 3. 纠正 3 条误判

| 条目 | 原判读 | 现判读 | 原因 |
|---|---|---|---|
| `kaleidoscope` | 无明示授权 | **GFDL** | credit 明写 GNU Free Documentation License |
| `mirror-repeat` | 无明示授权 | **GFDL** | 同上 |
| `sepia-toning` | 无明示授权 | **公有领域** | credit 明写 Library of Congress / No known restrictions |

这 3 张图片文件**从未被删过**，一直在包里——之前的「误判」发生在分类标签上。纠正后它们的
`imageRedistributable` 从「需人工判读」变成 `true`。
