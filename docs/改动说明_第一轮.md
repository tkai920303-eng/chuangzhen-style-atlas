4. 最后全网搜索光影库相关资源，同步本地化建立。

### 3.4 配色不是手填的

本地风格与 atlas 条目的色板，**全部从参考图实际提取**：

- 工具：`04_工具\提取配色.mjs`
- 原理：`ffmpeg -i X -vf scale=64:36 -f rawvideo -pix_fmt rgb24 -` 解码 → 4bit 直方图量化 →
  按欧氏距离 < 60 合并相近色 → 取占比前 6 色并附比例
- 产出：`04_工具\_抓取缓存\配色板.json`（**542 张全部提取成功**）
- 已实现风格包（lowbit-pixel / flat-motion / 6 种语义环境）用**文档里的固定色板**，
  不从截图反推（例如 lowbit-pixel 的 17 个色值直接来自 `style-spec.md`）

### 3.5 <私有工程>白模化（任务 3）

**设计原则：白模版只继承运动学，外观全部中性化。**

对 240 条 motion-prompt 条目逐条生成：

- 造型：中性灰白几何体（哑光 `#e8e8e8`），无贴图 / 无光泽 / 无反射 / 无金属感 / 无风格化笔触；
  轮廓用 1px 浅灰描边（`#b4b4b4`）保持可读性
- 阴影：单层柔和接触阴影（不透明度约 0.12），只指示物体与地面的关系，不参与造型塑造
- 背景：纯白或单一浅灰平涂，不加渐变 / 纹理 / 氛围粒子
- **唯一继承项**：时序、缓动、幅度（从原文规格中互斥分桶抽取，三段不重复）
- 颜色处理：原文规格里的颜色词（coral / blue / yellow / mint …）统一替换为 `{颜色}`
- 可替换槽位 6 个：`{主体形状} {材质} {主色} {背景} {投影} {文字}`

白模版末尾明确用途：**先在白模版上验证节奏，确认后再套具体风格的配色、材质与质感**。

## 四、HTML 视觉参考图鉴

`05_工作台\public\atlas.html` —— **单文件自包含，5.27 MB**，三库数据全部内联。

- **零依赖**：无 CDN、无框架、无外部请求，双击即可打开
- **双击打开也能看图**：脚本按 `location.protocol` 自适应图片路径
  （`file:` → `../../02_素材/图片库/风格参考图/`，HTTP → `/atlas-img/`）
- 三个页签（风格库 551 / <私有工程> 348 / 光影库 130）+ 分类筛选条 + 全文搜索
- 卡片显示参考图、名称、英文名、摘要、配色色块；点开右侧抽屉看全部字段
- **复制按钮**
  - 风格库：「一键复制风格配置」（完整提示词）+「复制效果指令」（atlas 的 LetzAI 指令）
  - <私有工程>：「复制动效提示词」+「复制白模版」+「复制元素代码」
  - 光影库：「复制光影提示词」
  - 顶栏另有「复制筛选清单」「复制全部提示词」，可按当前筛选批量取走
- 复制走 `navigator.clipboard`，`file://` 下自动降级到 `execCommand`
- 生成器 `04_工具\生成图鉴HTML.mjs` 内置**内联脚本语法自检**：
  抽出 `<script>` 块跑 `node --check`，不通过则退出码非 0
  （首版正是靠这道自检发现模板字符串吃掉了内层引号，导致页面 `SyntaxError`）

### 三个坑（已修复并固化为脚本）

1. `new URL(import.meta.url).pathname` 会把中文路径转成 `%E5%88%9B…` 字面量，
   目录被建成乱码名 → 改用 `fileURLToPath`。
2. HTML 生成器用模板字符串包住整份页面，内层 `\'` 被外层吃掉 → 抽出内联脚本做 `node --check` 自检。
3. Node 直连外网 DNS 失败（`EAI_AGAIN`），本机走 `HTTP_PROXY=127.0.0.1:7897` →
   抓取一律用 `curl.exe`（或 `Invoke-WebRequest`），不走 Node 的 `https` 模块。

### 另外两处修复

4. **抽屉遮罩层盖住顶栏**：遮罩 `z-index:40` 高于顶栏 `z-index:30`，抽屉打开时点页签没反应。
   已改为遮罩 35 / 顶栏 40 / 抽屉 41，顶栏保持可点。
5. **工作台进程是提权进程**：旧实例 PID <pid> 由提权链拉起，当前会话 `taskkill` 报
   `Access is denied`，`launch.mjs stop` 也杀不掉。已用 `Start-Process -Verb RunAs` 触发一次提权终止，再由 `launch.mjs start` 在 **<port>** 起新实例（PID <pid>）。
   ⚠ **下次重启工作台若报「端口 <port> 仍被占用」，就是这个原因，需要同样的提权终止**。

## 八、已知限制

1. **atlas 的 504 条是「视觉处理/风格」条目，不全是画风**。本轮按用户要求整体并入风格库，
   按「历史年代」与「机器章节」分 38 个分类筛选。若后续只想留纯画风，可按 `category` 过滤。
2. **motion-prompt 的运动规格只有日文与英文**，没有简体版（`name`/`meaning`/`ask`/`summary` 有简中）。
   因此条目名、含义、问法是中文，**时序/缓动/幅度保持英文原文**（数值与公式准确，不做不可靠的转译）。
3. **本地 108 条动效/组件只是引用**（`sourcePath` 指向工程内文件），未做白模化——
   它们是「已在工程里实现的组件」，白模化只对有完整规格的 motion-prompt 240 条有意义。
4. `02_素材\图片库\风格参考图` 里的 atlas 图片**版权各自不同**（Wikimedia CC、公共领域、授权演示图等）。
   条目里保留了 `credit` 与 `gallery[].license` 字段，**商用前需逐条核对授权**。
5. 图鉴页 5.27 MB，浏览器一次性解析；条目数再翻倍时建议改为按需拉取 `/api/atlas/<lib>`。
