# 数据来源与授权

本文件说明本库**每一条**内容的来源与授权。条目级的溯源信息同时冗余存放在 `data/*.json` 里：

| 字段 | 含义 |
|---|---|
| `source` | 来源代号：`local` / `atlas` / `motion-prompt` / `web` |
| `sourceName` | 来源名称（含作者与许可说明） |
| `sourceUrl` | 条目原始页面地址 |
| `license` | 该条目的授权（`MIT` / `null` / 其他） |
| `credit` | **主参考图的权利声明原文**（atlas 条目；atlas 只在 `effect.credit` 自由文本里交代，`effect.image` 字段没有 license） |
| `imageLicense` | 主参考图的判读类别（公有领域 / CC0 / CC 署名类 / GFDL / 无明示授权 / Atlas 自制插画 / 版权保留） |
| `imageRedistributable` | 主参考图能否再分发（`true` / `false` / `需授权` / `需人工判读`） |
| `gallery[].license` / `gallery[].artist` | 历史例图逐张授权与作者（atlas 条目） |
| `gallery[].url` | 历史例图可访问地址（`src` 里的根相对路径已拼上 `https://atlas.letz.ai`） |
| `refs` | 参考图（相对 `assets/` 的路径） |
| `preview` | 循环动图（相对 `assets/` 的路径，仅部分条目有） |

> atlas 的 SKILL.md 原文：*Keep image author, source, and license with reused images;
> **public access does not imply unrestricted image licensing.***

来源：工程内已实现的动效与组件（16 条动效 + 114 条组件源码）。

### 2. motion-prompt 240 条 · `source: motion-prompt`

来源：[showheyohtaki/motion-prompt](https://github.com/showheyohtaki/motion-prompt)，10 个包 × 24 条。

- 授权：**MIT**

**本库未复制上述网站的任何图片**，只使用文字与参数，并据此绘制示意图（`assets/光影参考图/光影示意_*.png`）。

示意图的绘制规则：

- 俯视灯位盘：0° 为镜头轴（正面），90° 为侧面，180° 为背面；仰角越高灯位越靠近中心（半球投影）
- 色温条：K 值经色温近似算法转 RGB；区间（如 `2000–3000K`）画双色渐变
- 光比条：主光与辅光按 `主:辅` 比例画双色条
- 光质标记：从 `sourceType` / `hardness` 文本判为柔光 / 硬光 / 混合光
- 无法解析为离散灯位的条目（如全向环绕、天穹补光）保留原描述并在图上标注

## 五之二、脱敏说明

公开包里的本机绝对路径**统一脱敏**为 `<私有工程>/…` 相对示意路径（保留文件名与 `#调用点`）：

- 规则实现：`tools/脱敏.mjs`（`sanitizePath`）
- 生效范围：`data/风格库.json`、`data/动效库.json`、`data/光影库.json` 的 `sourcePath` / `sourcePath2`；
  `data/components.json` 另剥掉 `dir` / `file` 字段；规格卡 PNG 上烧的路径同样用脱敏后的值
- 本地素材库里的原始 JSON **保留真实路径**（本地复现需要），只有导出的公开包脱敏

## 五之三、第三方素材剔除

素材库的**本地库**保留第三方素材（第三方原片截帧、音轨、字幕与拆解报告），供检索、复刻参考与版权溯源；
**发布包一律剔除**。剔除清单是 `tools/库源/第三方素材.json`（路径相对本地素材投放区，无绝对路径）。

导出时（`tools/导出开源包.mjs`）执行三道防线：

| 防线 | 做法 |
|---|---|
| 路径防线 | 清单路径映射到包内可能位置，命中即删 |
| 内容防线 | 包内每个文件算 SHA-256 与清单文件比对，命中即删（改名、挪位也拦得住） |
| 引用防线 | `data/*.json` 中指向被删文件的 `refs` / `preview` 置空；`data/配色板.json` 同名键清除 |

导出末尾对整包再做一次残留断言：**仍有命中即导出失败（退出码非 0）**。
逐条统计见 [`第三方素材剔除记录.md`](第三方素材剔除记录.md)，机器可读版本见 `data/third-party-exclusion.json`；
`npm run smoke` 会独立重算整包哈希做复核。

## 六、复核依据

所有结论均可复核，不依赖印象：

```bash
npm run verify
```

该脚本检查：三库条目数与结构、提示词七段完整性、白模版槽位与去色、MIT 首行保留、三库引用图**逐个存在**、图鉴无外部依赖、复制按钮齐备。

图像层面的复核：

```bash
npm run render:verify   # 用 Chrome ImageDecoder 逐个读动图帧数与 animated 标记
node tools/预览渲染/验收图鉴页面.mjs   # 无头浏览器打开图鉴，逐页签统计破图数
```
