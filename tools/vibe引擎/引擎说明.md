# vibe 引擎件库（vk.js / vk-kit.js）

来源：[HeyChengC/vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film)，
MIT 许可（本目录 `LICENSE` 为原文）。上游 commit：62d51508aad00003dc6209afa80c4b5dc540de59。

## 这两个文件是什么

- `vk.js` —— 渲染核心：时间与数学、缓动、包络、随机、颜色、字体、场景与出帧（`window.VK.*`）。
- `vk-kit.js` —— 贯穿全片的「语法件」货架：字幕、片名卡、年份 HUD、章节标、骰子、点阵成字、数轴等（`window.VKit.*`）。

两者都是**纯浏览器 Canvas 代码，零依赖**，可直接在自己的页面里按 `vk.js` → `vk-kit.js` 的顺序引入。

## 为什么本目录只有这两个文件

上游另有 `render.py` / `audio.py` / `get_fonts.py` / `new_film.py`（Python 渲染管线与字体下载），
需要 Python + Playwright + 本机 Chrome + ffmpeg，且要联网下载字体——与本仓库
「clone 下来 `npm start` 就能用、不需要联网」的承诺冲突，所以**没有随包分发**。

上游 `references/*.md`（方法文档原文）与 `examples/` 下的分镜表、样片图也**没有随包分发**：
方法文档里成段引用他人短片的字幕原句，样片图则未被上游的 MIT 授权覆盖
（上游许可只授权「引擎、脚本和文档里的方法说明」，且 examples/README 明写「能带走的是做法，不是画面」）。
方法结论已由本项目蒸馏进索引，读者不需要上游原文也能拿到全部可用结论。

要跑完整出片管线（逐帧截图 → 压片 → 混音），请用上游仓库：
https://github.com/HeyChengC/vibe-knowledge-film
